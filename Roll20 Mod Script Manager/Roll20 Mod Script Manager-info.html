Roll20 Mod Script Manager

게임에 설치한 모드 스크립트들의 명령어를 모아서 매크로로 만들어주는 스크립트입니다. 각 모드 스크립트 설정을 읽어와야 하기 때문에 Tampermonkey가 반드시 필요합니다.
각 스크립트의 상단 주석에 포함된 명령어만 인식합니다. 상단에 주석이 없다면 자주 쓰는 명령어와 이름을 입력해주세요.
완벽하게 이름을 불러오지 못할 수 있으니, 편집창에서 이름을 직접 수정해서 사용해주시기 바랍니다.
프로그램은 게임에 입장하면 자동으로 활성화되며 매크로 설정 후 호출 종료를 하면 다음 입장부터 반응하지 않습니다.
